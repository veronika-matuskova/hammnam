# hamMňam 🍲

A lightweight, serverless web application for recipe management focused on nutritional values (carbohydrate units / CU, carbs, and glycemic index), built for speed and hosted on GitHub Pages.

## 🚀 Tech Stack
- **Frontend:** HTML5, Tailwind CSS (via CDN), **Alpine.js**
- **Backend & Database:** **Supabase** (PostgreSQL + REST API / JS Client)
- **Hosting:** GitHub Pages (with automated CI/CD deployment)

## ✨ Key Features
- 📋 **Recipe Management:** Browse, add, and manage recipes with multilingual support (Czech & Slovak).
- 🩺 **Diabetic Parameters:** Track **CU** (Carbohydrate Units / SJ), total carbohydrates in grams, and **GI** (Glycemic Index).
- ⭐ **Favorites:** Bookmark recipes with a star for quick access.
- 🌐 **Localization:** Built-in UI language switcher (CZ/SK).
- ☁️ **Cloud Storage:** Secure data storage in Supabase, protected by Row Level Security (RLS) policies.
